## 🐛 Se Algo Não Funcionar

| Problema | Solução |
|----------|---------|
| Chrome não abre | Certifique-se que Chrome está instalado |
| Login timeout | Aumente tempo em script (default 300s = 5 min) |
| Nenhum produto encontrado | Produtos podem estar em outra aba ou não publicados |
| Erro ao salvar | Rollback automático foi executado |
