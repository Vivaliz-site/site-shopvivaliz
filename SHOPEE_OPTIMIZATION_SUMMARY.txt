================================================================================
METRICAS DE SEO IMPLEMENTADAS
================================================================================

Score SEO (0-100) baseado em:

  [Comprimento]
  - Ideal: 30-110 caracteres
  - Minimo: 10 caracteres
  - Maximo: 120 caracteres (limite Shopee)

  [Palavras-chave]
  - "qualidade" (+10 pontos)
  - "novo/lacrado" (+8 pontos)
  - "original" (+8 pontos)
  - "premium" (+7 pontos)
  - "promocao/desconto" (+5 pontos)
  - "pronta entrega/frete gratis" (+5 pontos)

  [Especificacoes]
  - Tamanho (mm, cm, polegada)
  - Cor
  - Material
  - Capacidade
  - Outros (peso, potencia, etc)

  [Qualidade de Texto]
  - Sem caracteres especiais desnecessarios
  - Sem palavras repetidas
  - Estrutura clara

================================================================================
CAPACIDADES
================================================================================

MODO 1: API SHOPEE (Automacao Total)
  ✓ Recupera TODO o catalogo (via API Partner v2)
  ✓ Analisa cada titulo
  ✓ Gera titulos otimizados com IA (OpenAI)
  ✓ Aplica mudancas automaticamente
  ✓ Verifica apos aplicar (read-back)
  ✓ Faz rollback se falhar
  ✓ Cria backups automaticamente
  ✓ Gera relatorios de mudancas

  Requisitos:
  - SHOPEE_PARTNER_ID
  - SHOPEE_PARTNER_KEY
  - SHOPEE_SHOP_ID
  - SHOPEE_ACCESS_TOKEN ou SHOPEE_REFRESH_TOKEN
  - OPENAI_API_KEY (opcional, para IA)

  Velocidade: ~3-5 minutos para catalogo inteiro

MODO 2: BROWSER AUTOMATION (Revisar Manualmente)
  ✓ Abre Chrome automaticamente
  ✓ Aguarda login manual (180 segundos)
  ✓ Analisa cada titulo com score SEO
  ✓ Exibe problemas e sugestoes
  ✓ Abre editor para titulos com score < 70
  ✓ Usuario aprova ou rejeita cada mudanca
  ✓ Controle total do usuario

  Requisitos:
  - Chrome/Chromium instalado
  - Selenium: pip install selenium
  - Nenhum token necessario

  Velocidade: ~2-5 minutos para primeiros 20 produtos

MODO 3: DEMO (Aprender)
  ✓ Mostra exemplos de analise SEO
  ✓ Exibe scores e sugestoes
  ✓ Nenhuma alteracao feita
  ✓ Educacional

  Requisitos: Nenhum

  Velocidade: ~5 segundos

================================================================================
COMO USAR
================================================================================

1. COMECAR (Aprender como funciona - SEM RISCO)
   $ python scripts/shopee_seo_demo.py

2. REVISAR (Revisar manualmente antes de aplicar)
   $ python scripts/shopee_seo_browser_optimizer.py

3. APLICAR (Automacao com API - recomendado)
   $ export SHOPEE_PARTNER_ID=seu_id
   $ export SHOPEE_PARTNER_KEY=sua_chave
   $ export SHOPEE_SHOP_ID=seu_shop_id
   $ export SHOPEE_ACCESS_TOKEN=seu_token
   $ python scripts/shopee_title_optimizer.py --method api

4. MONITORAR (Ver resultados)
   -> Acessar https://seller.shopee.com.br/analytics
   -> Monitorar por 24-48 horas
   -> Verificar impressoes, cliques e conversoes
