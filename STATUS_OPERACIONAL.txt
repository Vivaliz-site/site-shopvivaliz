CREDENCIAIS E SEGURANCA

  • Os valores dos secrets nao sao gravados neste arquivo.
  • O refresh token que funciona no GitHub Actions Production nao deve ser copiado para documentacao, chat ou logs.
  • A VM deve receber as credenciais somente pelo workflow seguro de sincronizacao.
  • O workflow de sincronizacao agora exige GOOGLE_ADS_REFRESH_TOKEN explicitamente e valida, na propria VM, se o refresh token consegue obter um access token do Google sem imprimir nenhum segredo.
  • Se a validacao da VM retornar invalid_grant, a sincronizacao deve falhar; nao deve mais registrar sucesso silencioso.
