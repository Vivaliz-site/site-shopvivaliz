# Validação visual histórica — 2026-07-24

Este documento continha um secret de webhook em texto puro. O valor foi removido e deve ser considerado comprometido.

Screenshots e relatórios visuais não devem incluir tokens, cookies, cabeçalhos de autorização, senhas ou respostas completas de autenticação. Uma validação atual exige:

- screenshot sem dados sensíveis;
- run e commit identificados;
- testes executados;
- resultado do endpoint;
- read-back quando houver mutação;
- artifact imutável.

Este snapshot não comprova configuração atual de produção. A rotação do secret no provedor permanece obrigatória.
