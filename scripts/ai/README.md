# Scripts de Agentes IA

Esta pasta contém implementações canônicas de executores, geradores e ferramentas de agentes.

Os arquivos equivalentes diretamente em `scripts/` são wrappers temporários para compatibilidade. Código novo deve usar os caminhos desta pasta.

Toda rotina criada ou migrada aqui deve ser registrada em `docs/knowledge/routines-registry.md`.
