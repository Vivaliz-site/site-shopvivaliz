# Ferramentas legadas de dados e preços

Utilitários históricos de planilhas, SKUs, preços e integração Tiny/Olist.

Estes scripts não são rotinas canônicas de produção. Alguns podem alterar dados externos. Antes de executar, revise entradas, saídas, credenciais, backup, confirmação e read-back.

Os caminhos antigos na raiz permanecem como wrappers temporários.
