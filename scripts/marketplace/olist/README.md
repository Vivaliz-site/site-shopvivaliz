# Integração Olist/Tiny ERP

Esta pasta contém implementações canônicas de autenticação, sincronização, imagens, catálogo e monitoramento Olist.

Use `OLIST_*` como nomes canônicos para fluxos Olist/ERP. Use `TINY_*` somente quando uma API Tiny nativa exigir credencial própria.

Os arquivos antigos diretamente em `scripts/` permanecem como wrappers temporários.
