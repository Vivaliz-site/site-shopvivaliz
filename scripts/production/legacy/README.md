# Executores de produção legados

Estes arquivos foram retirados dos caminhos operacionais principais por apresentarem risco de alteração direta, deploy antigo ou ausência de guardrails modernos.

Não execute diretamente. Os wrappers antigos exigem confirmação explícita por variável de ambiente. Para reativar uma rotina, crie PR específico com backup, canário, rollback/read-back e validação objetiva.
